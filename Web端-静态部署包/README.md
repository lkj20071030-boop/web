# 智析 AI · Web 静态演示版

来自 10-成品提交/02-Web端/dist，仅包含浏览器端。
本部署副本使用相对资源路径，默认启用项目已有的 mock 演示模式。
演示模式使用预设电路示例，真实后端支持的三主题和真实模型功能不等同于此静态版本。
Node 服务未包含在这个静态部署包中；GitHub Pages 不运行服务端。

发布：将本文件夹里面的全部内容上传到 GitHub 仓库根目录。
Settings → Pages → Source: Deploy from a branch → main → /(root) → Save。
访问 Pages 提供的 Visit site 链接。自动演示位于同一网址下的 demo.html。
若浏览器曾保存真实后端设置，请在偏好与连接中切换演示模式并保存。
